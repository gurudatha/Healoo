RUST LIBRARIES IN THE HEALOO BACKEND (care-api) BUILD
=====================================================

Source: libraries.txt (cargo build --release; 323 libraries, plus care-api itself).
Each entry: what the library is / what it does here / who needs it.
Libraries marked "build time" only run while compiling and are not part of
the finished program. Where two versions appear, different libraries depend
on different major versions; Cargo builds both. "Pulled in indirectly" means
another library depends on it and the exact chain isn't worth tracing here.


1. LIBRARIES CARE-API USES DIRECTLY (listed in Cargo.toml)
----------------------------------------------------------

tokio (1.53.1)
  Asynchronous runtime for Rust: schedules tasks, timers, sockets and files.
  Everything in the server runs on it: HTTP, WebSocket, Cassandra, Kafka calls.
  Direct dependency ("full" features); the heart of care-api.

tokio-util (0.7.19)
  Extra utilities for tokio, such as codecs and cancellation tokens.
  care-api uses CancellationToken to stop the server and consumers cleanly.
  Direct dependency; also used by hyper, h2 and tower.

axum (0.7.9)
  Web framework built on hyper and tower: routes, extractors, JSON, WebSocket.
  Defines all /v1 routes, the Principal extractor and the /v1/ws upgrade.
  Direct dependency (features ws, macros).

axum-server (0.7.3)
  Server runner for axum that adds TLS via rustls.
  Serves HTTPS directly in the LAN profile (LAN_TLS=builtin).
  Direct dependency (feature tls-rustls).

tower (0.5.3, 0.4.13)
  Middleware abstraction: Service and Layer traits, timeouts, limits.
  axum is built on it; care-api stacks its layers on the router.
  Direct dependency 0.4; 0.5 comes in through reqwest/hyper-util.

tower-http (0.6.11, 0.5.2)
  Ready-made HTTP middleware: CORS, tracing, body limits, request IDs.
  Provides the CORS, request-id, trace and security-header layers.
  Direct dependency 0.5; 0.6 comes in through reqwest.

futures (0.3.34)
  Core future/stream traits and combinators (StreamExt, SinkExt, select).
  Used to split the WebSocket into sender and receiver halves.
  Direct dependency; umbrella over the futures-* crates.

serde (1.0.229)
  Framework for serialising and deserialising Rust data.
  Every JSON request, response, event envelope and config shape uses it.
  Direct dependency; derive macros come from serde_derive.

serde_json (1.0.151)
  JSON reader and writer built on serde.
  Parses API bodies, builds responses, and encodes Kafka event payloads.
  Direct dependency.

uuid (1.26.1)
  Generates, parses and formats UUIDs (v1 time-based, v4 random).
  User IDs are v4; item, thread and message IDs are v1 (Cassandra timeuuid).
  Direct dependency (features v1, v4, serde).

chrono (0.4.45)
  Date and time types, formatting and parsing.
  Item dates, message timestamps, token expiry and event times.
  Direct dependency.

ulid (1.2.1)
  Sortable unique identifiers (time + randomness, 26 characters).
  Event IDs, request IDs and uploaded file names.
  Direct dependency.

jsonwebtoken (9.3.1)
  Creates and verifies JSON Web Tokens (JWT).
  Verifies Auth0 RS256 tokens and signs/verifies the HS256 dev tokens.
  Direct dependency; uses ring for the cryptography.

reqwest (0.12.28)
  High-level HTTP client.
  Downloads Auth0's public signing keys (JWKS).
  Direct dependency (rustls TLS, JSON).

scylla (0.13.2)
  Async CQL driver for ScyllaDB and Apache Cassandra.
  All database access in src/store goes through its Session.
  Direct dependency 0.13.

rdkafka (0.36.2)
  Rust wrapper around librdkafka, the standard C Kafka client.
  Producer and consumers for the event topics (doc section 6).
  Direct dependency (feature cmake-build).

aws-config (1.12.0)
  Loads AWS settings: region, credentials from environment or files.
  Configures the S3 client when FILE_STORE=s3 (MinIO or AWS S3).
  Direct dependency.

aws-sdk-s3 (1.149.0)
  Official AWS SDK client for Amazon S3 (also works with MinIO).
  Presigned upload/download URLs and file reads/writes in S3Store.
  Direct dependency.

image (0.25.10)
  Decodes, edits and encodes images (JPEG, PNG, WebP).
  Makes attachment thumbnails in the media worker and seed sample images.
  Direct dependency (jpeg, png, webp only).

lopdf (0.33.0)
  Reads, edits and writes PDF files.
  Counts PDF pages in the media worker and builds seed sample PDFs.
  Direct dependency.

rcgen (0.13.2)
  Generates X.509 certificates and keys.
  Creates the local trial CA and the LAN server certificate.
  Direct dependency (feature x509-parser to reload the CA).

local-ip-address (0.6.13)
  Finds this machine's local network IP address.
  The LAN profile uses it to build the default public URL.
  Direct dependency.

mdns-sd (0.11.5)
  Multicast DNS service discovery (Bonjour/Zeroconf).
  Announces _healoo._tcp on the local network when run natively.
  Direct dependency.

ipnet (2.12.2)
  IP network (CIDR) types such as 10.0.0.0/8.
  Parses TRUSTED_PROXIES to decide which X-Forwarded-For to trust.
  Direct dependency; also used by reqwest.

url (2.5.8)
  Parses and builds URLs (WHATWG standard).
  Public base URL, WebSocket URL and signed file links.
  Direct dependency; also used by reqwest and the AWS SDK.

async-trait (0.1.92)
  Macro that allows async functions in traits.
  Used by the Exposure, TokenVerifier, ObjectStore and EventBus traits.
  Direct dependency.

dashmap (5.5.3, 6.2.1)
  Concurrent hash map that many threads can use at once.
  Prepared-statement cache, WebSocket registry, token and rate-limit caches.
  Direct dependency 6.x; 5.x comes in through scylla.

thiserror (1.0.69, 2.0.20)
  Derive macro for writing error types.
  Defines AuthError in the auth module.
  Direct dependency 1.x; 2.x is used by other libraries.

anyhow (1.0.104)
  Easy error type for applications, with context messages.
  Most internal functions return anyhow::Result.
  Direct dependency.

tracing (0.1.44)
  Structured, levelled logging and spans.
  All log lines in care-api (info!, warn!, error!).
  Direct dependency.

tracing-subscriber (0.3.23)
  Collects tracing events and prints them.
  Text logs on the LAN, JSON logs on the internet; RUST_LOG filtering.
  Direct dependency (env-filter, json).

base64 (0.22.1)
  Base64 encoding and decoding.
  Listed in Cargo.toml; also used by jsonwebtoken, rustls and others.
  Direct dependency.

hmac (0.12.1, 0.13.0)
  HMAC message authentication codes (RustCrypto).
  Signs and checks the /files URLs of the disk store.
  Direct dependency 0.12; 0.13 is a newer release used elsewhere.

sha2 (0.11.0, 0.10.9)
  SHA-224/256/384/512 hash functions (RustCrypto).
  SHA-256 of attachments and the HMAC for signed file URLs.
  Direct dependency 0.10; 0.11 is a newer release used elsewhere.

hex (0.4.3)
  Hexadecimal encoding and decoding.
  Formats SHA-256 hashes and URL signatures as text.
  Direct dependency.

rand (0.8.8, 0.9.5)
  Random number generation.
  Random Healoo IDs (HL-xxxxx) and the v1 UUID node id.
  Direct dependency 0.8; 0.9 is used by other libraries.

bytes (1.12.1)
  Efficient byte buffers that can be shared without copying.
  File contents passed between the API, object store and worker.
  Direct dependency; also core to hyper, tokio and the AWS SDK.


2. ASYNC RUNTIME AND CONCURRENCY
--------------------------------

tokio-macros (2.7.2)
  Procedural macros for tokio, mainly #[tokio::main] and #[tokio::test].
  Turns care-api's async main function into a program entry point.
  Used by tokio.

mio (1.2.3)
  Low-level, non-blocking I/O (epoll on Linux, kqueue on macOS, IOCP on Windows).
  The layer under tokio that waits for sockets to become ready.
  Used by tokio.

socket2 (0.6.5, 0.5.10)
  Cross-platform access to low-level socket options.
  Lets networking code set options std::net doesn't expose.
  Used by tokio, hyper-util and mdns-sd (two versions).

signal-hook-registry (1.4.8)
  Registers operating-system signal handlers safely.
  Lets tokio react to Ctrl-C and SIGTERM (docker stop).
  Used by tokio.

pin-project-lite (0.2.17)
  Lightweight macro for safe pinned fields in futures.
  Needed for hand-written futures and streams.
  Used by tokio, hyper, tower, tracing and others.

pin-utils (0.1.0)
  Small helpers for pinning values.
  Legacy helper for futures code.
  Used by futures-util.

futures-core (0.3.34)
  Core Future and Stream traits for the futures ecosystem.
  The minimal shared definitions other async crates depend on.
  Used by futures, tokio-util, hyper, axum.

futures-sink (0.3.34)
  The Sink trait (something you can send values into).
  Used for sending WebSocket messages.
  Part of the futures family.

futures-channel (0.3.34)
  Async channels (oneshot, mpsc) for futures.
  Passing values between async tasks.
  Part of the futures family; used by hyper.

futures-task (0.3.34)
  Tools for building task wakers.
  Low-level support for executors.
  Part of the futures family.

futures-io (0.3.34)
  Async versions of Read and Write traits.
  Common I/O traits for non-tokio code.
  Part of the futures family.

futures-util (0.3.34)
  Combinators and helpers for futures and streams.
  StreamExt/SinkExt methods such as next() and split().
  Part of the futures family.

futures-macro (0.3.34)
  Macros such as join! and select! for futures.
  Generates code for waiting on several futures at once.
  Part of the futures family.

futures-executor (0.3.34)
  Simple executors that run futures to completion.
  Rarely used on its own in tokio programs.
  Part of the futures family.

slab (0.4.12)
  Pre-allocated storage with reusable slots.
  Efficient storage for tasks and connections.
  Used by futures-util and h2.

parking_lot (0.12.5)
  Faster, smaller Mutex and RwLock implementations.
  Locks used inside tokio and the drivers.
  Used by tokio, dashmap and others.

parking_lot_core (0.9.12)
  Core thread-parking logic behind parking_lot.
  Puts threads to sleep and wakes them.
  Used by parking_lot and dashmap.

lock_api (0.4.14)
  Common traits for building lock types.
  Foundation that parking_lot and spin build on.
  Used by parking_lot and spin.

scopeguard (1.2.0)
  Runs cleanup code when a scope ends (defer).
  Ensures locks and state are restored on early exit.
  Used by lock_api.

atomic-waker (1.1.2)
  Stores a task waker that can be updated atomically.
  Wakes a waiting task when data arrives.
  Used by h2 and hyper.

sync_wrapper (1.0.2)
  Makes a non-Sync value safe to share by allowing only exclusive access.
  Lets bodies and futures be used across threads.
  Used by axum and reqwest.

try-lock (0.2.5)
  Very small lock that never blocks, it only tries.
  Coordinates hyper's client connections.
  Used by want.

want (0.3.1)
  Signals when a consumer wants the next value.
  Flow control between hyper's client and its connections.
  Used by hyper.

polling (2.8.0)
  Portable interface to epoll/kqueue/IOCP.
  Waits for network events without tokio.
  Used by mdns-sd.

flume (0.11.1)
  Fast multi-producer, multi-consumer channel.
  Sends messages between mdns-sd's threads.
  Used by mdns-sd.

spin (0.10.1, 0.9.9)
  Spin-based locks and lazy values that need no operating system.
  Simple locks in low-level crates.
  Used by flume and others (two versions).

crossbeam-utils (0.8.23)
  Utilities for concurrent programming (cache padding, scoped threads).
  Building block for rayon's work-stealing queues.
  Used by rayon via crossbeam-deque/epoch.

crossbeam-epoch (0.9.21)
  Memory reclamation for lock-free data structures.
  Lets rayon's queues free memory safely.
  Used by crossbeam-deque.

crossbeam-deque (0.8.8)
  Work-stealing queues.
  Balances work across rayon's threads.
  Used by rayon-core.

rayon (1.12.0)
  Easy data parallelism (parallel iterators).
  Speeds up image and PDF processing on several CPU cores.
  Used by image and lopdf.

rayon-core (1.13.0)
  Thread pool behind rayon.
  Runs rayon's parallel jobs.
  Used by rayon.

arc-swap (1.9.2)
  Atomically swappable shared pointer.
  Lets code replace shared configuration without locks.
  Used by scylla.

thread_local (1.1.10)
  Per-object thread-local storage.
  Keeps per-thread state in the log filter.
  Used by tracing-subscriber.

sharded-slab (0.1.7)
  Lock-free concurrent slab allocator.
  Stores span data for the tracing subscriber.
  Used by tracing-subscriber.

once_cell (1.21.4)
  Values that are initialised once, lazily.
  Global values created on first use.
  Used by many crates (tracing, regex, AWS SDK).

lazy_static (1.5.0)
  Older macro for lazily initialised globals.
  Same idea as once_cell, older style.
  Used by tracing-subscriber and others.


3. HTTP, WEB SERVER AND WEBSOCKET
---------------------------------

http (1.5.0, 0.2.12)
  Standard HTTP types: Request, Response, headers, methods, status codes.
  Shared vocabulary for axum, hyper, reqwest and tower.
  Used everywhere; 0.2 is also present for the older AWS SDK TLS stack.

http-body (1.1.0, 0.4.6)
  Trait describing an HTTP body that arrives in chunks.
  Lets servers and clients stream bodies.
  Used by hyper, axum and the AWS SDK (two versions).

http-body-util (0.1.5)
  Helpers for http-body (collect a body, empty and full bodies).
  Reads whole request bodies such as uploads.
  Used by axum, reqwest and hyper-util.

httparse (1.10.1)
  Fast, zero-copy HTTP/1 request and response parser.
  Parses incoming HTTP requests for hyper.
  Used by hyper.

httpdate (1.0.3)
  Formats and parses HTTP dates.
  Writes the Date header.
  Used by hyper.

hyper (1.11.1, 0.14.32)
  Fast, correct HTTP/1 and HTTP/2 implementation.
  The HTTP engine under axum, axum-server and reqwest.
  Used by axum and reqwest (1.x); 0.14 by the AWS SDK's older TLS stack.

hyper-util (0.1.20)
  Utilities around hyper 1.x: connection pools, server helpers.
  Connects hyper to tokio sockets.
  Used by axum, axum-server and reqwest.

h2 (0.4.19, 0.3.27)
  HTTP/2 protocol implementation.
  Allows HTTP/2 connections.
  Used by hyper (two versions).

tower-service (0.3.3)
  The Service trait: request in, response future out.
  Defines what a handler or middleware looks like.
  Used by tower, axum and hyper.

tower-layer (0.3.3)
  The Layer trait for wrapping services with middleware.
  Lets layers such as CORS wrap the router.
  Used by tower and axum.

axum-core (0.4.5)
  Core types and traits of axum (extractors, responses).
  Stable base shared by axum and its add-ons.
  Used by axum.

axum-macros (0.4.2)
  Macros for axum, such as #[debug_handler].
  Better compile errors for handlers.
  Used by axum (feature macros).

matchit (0.7.3)
  Fast URL router (radix tree).
  Matches paths such as /v1/items/:id to handlers.
  Used by axum.

mime (0.3.17)
  MIME types such as application/json.
  Content-type handling.
  Used by axum and reqwest.

serde_urlencoded (0.7.1)
  Reads and writes URL-encoded form data with serde.
  Decodes query strings like ?status=OPEN&limit=20.
  Used by axum (Query extractor) and reqwest.

serde_path_to_error (0.1.20)
  Reports which field failed when deserialising.
  Clearer JSON error messages from axum.
  Used by axum.

form_urlencoded (1.2.2)
  Parses and builds application/x-www-form-urlencoded strings.
  Query parameters in signed file URLs.
  Used by url.

percent-encoding (2.3.2)
  Percent-encodes and decodes text for URLs.
  Escapes characters in URL paths and queries.
  Used by url and the AWS SDK.

urlencoding (2.1.3)
  Simple URL percent-encoding functions.
  Escapes values in request URLs.
  Used by the AWS SDK.

tungstenite (0.24.0)
  WebSocket protocol implementation (framing, handshake).
  Speaks the WebSocket protocol for /v1/ws.
  Used by tokio-tungstenite.

tokio-tungstenite (0.24.0)
  Runs tungstenite WebSockets on tokio.
  The engine behind axum's WebSocket support.
  Used by axum (feature ws).

utf-8 (0.7.6)
  Incremental UTF-8 decoder.
  Checks that WebSocket text frames are valid UTF-8.
  Used by tungstenite.

data-encoding (2.11.1)
  Encodings such as base64 and hex.

  Used by tungstenite.

sha1 (0.10.7, 0.11.0)

encoding_rs (0.8.41)

4. TLS (HTTPS) AND CRYPTOGRAPHY
-------------------------------

rustls (0.23.45, 0.21.12)
  TLS library written in Rust (no OpenSSL).
  Encrypts HTTPS: the LAN server, reqwest to Auth0, and the AWS SDK.
  Used by axum-server and reqwest (0.23); 0.21 by the AWS SDK's older stack.

rustls-pki-types (1.15.1)
  Shared types for certificates and private keys.
  Passes certificates between rustls crates.
  Used by rustls and related crates.

rustls-webpki (0.101.7, 0.103.15)
  Checks certificate chains for rustls.
  Verifies Auth0's and S3's certificates.
  Used by rustls (two versions).

rustls-pemfile (2.2.0)
  Reads certificates and keys from PEM files.
  Loads the LAN server certificate and key.
  Used by axum-server.

rustls-native-certs (0.8.4)
  Loads the operating system's trusted root certificates.
  Lets HTTPS clients trust what the OS trusts.
  Used by the AWS SDK HTTP client.

openssl-probe (0.2.1)
  Finds where the system keeps its CA certificate files.
  Helps rustls-native-certs on Linux.
  Used by rustls-native-certs.

webpki-roots (1.0.9)
  Mozilla's trusted root certificates, built into the program.
  Trust anchors for reqwest when calling Auth0.
  Used by reqwest (rustls-tls).

tokio-rustls (0.24.1, 0.26.5)
  Runs rustls TLS connections on tokio.
  TLS for the LAN server and HTTPS clients.
  Used by axum-server and hyper-rustls (two versions).

hyper-rustls (0.24.2, 0.27.10)
  Connects hyper's client with rustls.
  HTTPS for reqwest and the AWS SDK.
  Used by reqwest and the AWS SDK (two versions).

sct (0.7.1)
  Certificate Transparency checks (older rustls).
  Part of rustls 0.21's certificate checks.
  Used by rustls 0.21.

ring (0.17.14)
  Fast, audited cryptography primitives.
  RSA signature checks for Auth0 tokens; crypto for older rustls.
  Used by jsonwebtoken and rustls 0.21.

untrusted (0.9.0)
  Safe parsing of untrusted input bytes.
  Used when ring reads keys and signatures.
  Used by ring and rustls-webpki.

aws-lc-rs (1.18.1)
  Rust bindings to AWS-LC, Amazon's fork of BoringSSL crypto.
  Default crypto provider for rustls 0.23 and the AWS SDK.
  Used by rustls and the AWS SDK.

aws-lc-sys (0.45.0)
  Builds the AWS-LC C library during compilation.
  Needs cmake and a C compiler; one of the slowest parts of the build.
  Used by aws-lc-rs.

digest (0.10.7, 0.11.3)
  Common traits for hash functions (RustCrypto).
  Lets SHA-1, SHA-256 and MD5 share one interface.
  Used by sha1, sha2, md-5 and hmac (two versions).

crypto-common (0.1.7, 0.2.2)
  Shared traits for RustCrypto algorithms.
  Base definitions for digest and hmac.
  Used by digest (two versions).

block-buffer (0.10.4, 0.12.1)
  Buffers data into fixed-size blocks for hashing.
  Feeds input to block-based hashes like SHA-256.
  Used by digest (two versions).

generic-array (0.14.7)
  Arrays whose length is set by a type.
  Fixed-size hash outputs in RustCrypto 0.10.
  Used by digest 0.10.

typenum (1.20.1)
  Numbers represented as types, checked at compile time.
  Gives generic-array its lengths.
  Used by generic-array.

hybrid-array (0.4.15)
  Newer fixed-size array type for RustCrypto.
  Replaces generic-array in the newer RustCrypto releases.
  Used by digest 0.11 and related crates.

md-5 (0.11.0, 0.10.6)
  MD5 hash function (RustCrypto).
  Content-MD5 checks for S3; PDF encryption support in lopdf.
  Used by the AWS SDK and lopdf (two versions).

subtle (2.6.1)
  Constant-time operations for cryptography.
  Compares secrets without leaking timing information.
  Used by RustCrypto crates.

zeroize (1.9.0)
  Securely wipes secrets from memory.
  Clears keys when they are no longer needed.
  Used by rustls, aws-lc-rs and RustCrypto crates.

cpufeatures (0.2.17, 0.3.1)
  Detects CPU features such as SHA or AES instructions at runtime.
  Chooses the fastest hash implementation for the CPU.
  Used by sha1 and sha2 (two versions).

cmov (0.5.4)
  Constant-time conditional move.
  Selects values without timing leaks.
  Used by newer RustCrypto crates.

ctutils (0.4.2)
  Constant-time helper utilities.
  Support for timing-safe cryptography.
  Used by newer RustCrypto crates.

const-oid (0.9.6, 0.10.2)
  Object identifiers (OIDs) usable at compile time.
  Names algorithms inside certificates.
  Used by der and x509 crates (two versions).

der (0.7.10)
  Reads and writes DER, the binary encoding of certificates.

  Turns features on for newer compilers.
  Used by generic-array and ahash (build time).

rustversion (1.0.23)
  Conditional code based on the compiler version.
  Selects code for stable or newer Rust.
  Used by several crates.

rustc_version (0.4.1)
  Reads the rustc version from build scripts.
  Decides build options by compiler version.
  Used by some build scripts.

semver (1.0.28)
  Semantic version numbers.
  Compares compiler and crate versions.
  Used by rustc_version.

core_detect (1.0.0)
  Detects CPU features in no_std code.
  Picks accelerated code paths at runtime.
  Pulled in indirectly by another library.

multiversion (0.9.0)
  Compiles one function for several CPU feature sets.
  Chooses the fastest version on the running CPU.
  Pulled in indirectly by another library.

multiversion-macros (0.9.0)
  Macros behind multiversion.
  Generates the per-CPU copies.
  Used by multiversion.

multiversion_no_op (1.0.0)
  Placeholder version of multiversion that does nothing.
  Used when runtime CPU dispatch is turned off.
  Pulled in indirectly by another library.
